# 開発マイルストーン WBS

Excelで使うオリジナルWBSテンプレートです。予定・実績のガントチャート、休日を除いた終了日計算、マイルストーン、カミナリ戦、簡易集計を含みます。

## 作成

```powershell
py -3 .\generate_wbs.py
```

生成物は `開発マイルストーン_WBS.xlsx` です。

## マクロを有効にする場合

> `WBS_Macro.bas` と `InputFormHelper.cls` は Excel で読み込む前に Shift_JIS で保存してください。UTF-8 のままだと、Excel で文字化けが発生します。

1. `開発マイルストーン_WBS.xlsx` をExcelで開きます。
2. `Alt+F11`でVBEを開きます。
3. VBE の左ペインにある `Project - 開発マイルストーン WBS` を確認し、`ファイル > ファイルのインポート` から `WBS_Macro.bas` を読み込みます。
4. VBE のメニューから `挿入 > UserForm` を選択し、UserFormを1つ追加します。プロパティウィンドウの `(Name)` を `WBSInputForm` に変更してください。
5. UserFormのデザイン画面は空のままで構いません。ラベル、テキストボックス、コンボボックス、ボタンは `InputFormHelper.cls` がフォーム表示時に自動生成します。
6. `ファイル > ファイルのインポート` から `InputFormHelper.cls` を読み込みます。このファイルは `UserForm` ではなく `Class Module` です。VBEの `Class Modules` に `InputFormHelper` が表示されることを確認してください。
7. もし取り込み後の名前が `Module1` になった場合は、その項目を右クリックして `名前の変更` を選び、`InputFormHelper` に変更します。同名のクラスが既にある場合は、重複する方を削除してから取り込んでください。
8. `InputFormHelper.cls` はフォームの実体ではなく、`WBSInputForm` を表示し、入力値をWBSシートへ書き戻す補助クラスです。
9. 名前を付けて保存で `Excel マクロ有効ブック (*.xlsm)` を選択します。
10. Excelの開発ツールを表示し、`挿入 > ボタン（フォーム コントロール）` から、以下のボタンをワークシートに配置します。

- `WBS更新`（`RefreshWBS` マクロに割り当て）
- `WBS入力`（`InputWBSRow` マクロに割り当て）
- `期間更新`（`SetProjectPeriod` マクロに割り当て）
- `追加行`（`AddWBSRow` マクロに割り当て）

1. それぞれのボタンに対応するマクロを割り当ててから、`Alt+F8` でマクロ一覧を開いて確認します。
2. `WBS更新` を押すと、先行タスク、休日、予定終了日、カミナリ戦が更新されます。
3. WBSシートの入力対象行を選択して `WBS入力` を押します。`WBS入力補助` フォームが表示されることを確認してください。
4. タスク名などを入力して `入力する` を押し、選択行へ値が書き戻され、ガントが更新されることを確認します。`キャンセル` を押した場合は、選択行を変更せずにフォームが閉じます。

### VBE での具体的な確認画面

VBEでは次の順で確認します。

1. `Alt+F11` を押して VBE を開く
2. 左側のプロジェクト一覧で `Modules` に `WBS_Macro` があり、`Class Modules` に `InputFormHelper` が表示されていることを確認する
3. `挿入 > UserForm` でUserFormを追加し、プロパティウィンドウの `(Name)` を `WBSInputForm` にする
4. UserFormは空のままにする。入力部品は `InputFormHelper` が実行時に作成する
5. Excelに戻り、WBSシートの入力対象行を選択して `WBS入力` ボタンを押す
6. `WBS入力補助` が表示され、`タスク名`、`担当`、`種別`、`開始日`、`日数`、`進捗率`、`先行ID`、`備考` の入力欄が表示されることを確認する
7. `入力する` を押し、フォームが閉じて選択行へ値が反映されることを確認する

> 重要: `InputFormHelper.cls` は `.frm` のようなフォームファイルではありません。VBEで作る `WBSInputForm` がフォーム本体で、`.cls` はそのフォームへ入力部品を追加して値を書き戻す補助ロジックです。

表示されるフォームの例:

- タイトル: `WBS入力補助`
- 入力項目: `タスク名` / `担当` / `種別` / `開始日` / `日数` / `進捗率` / `先行ID` / `備考`
- ボタン: `入力する` / `キャンセル`

この画面で値を入力して `入力する` を押すと、該当行のセルに書き戻され、`RefreshWBS` でガントが更新されます。

### ボタンの配置手順

1. Excelで `開発` タブを表示します。
2. `挿入` から `フォーム コントロール > ボタン` を選択します。
3. 目的のセルにボタンをドラッグして配置します。
4. `マクロの割り当て` ダイアログで、対応するマクロ名を選択します。
5. ボタン名を変更して、用途が分かるようにします。

例:

- `WBS更新` → `RefreshWBS`
- `WBS入力` → `InputWBSRow`
- `期間更新` → `SetProjectPeriod`
- `追加行` → `AddWBSRow`

## 入力ダイアログ

- WBSシートの入力したい行を選択し、マクロ `InputWBSRow` を実行します。
- 行の `種別` に応じて、フェーズ用・タスク用・マイルストーン用の入力フォームが自動で切り替わります。
- フェーズ、タスク、マイルストーンごとに当該行を補助しながら、タスク名、担当、予定開始日、予定日数、進捗率、先行ID、備考を入力できます。
- WBS表の範囲外を選択して実行した場合は、最初の空き行へ入力します。

## ガント表示期間

- `設定`シートの`B4`にプロジェクト開始月、`B5`にプロジェクト終了月を入力します。
- マクロ `RefreshWBS` または `SetProjectPeriod` を実行すると、開始月の1か月前から終了月の1か月後までガントの日付が更新されます。
- マクロ `SetProjectPeriod` を実行すると、開始月と終了月をダイアログで入力できます。
- 日付範囲を変更した後に `RefreshWBS` を実行すると、カミナリ戦も更新されます。

## 入力ルール

- 黄色セルが入力欄です。
- `予定開始` と `予定日数`を入力すると、休日を除いた`予定終了`が計算されます。
- `実績開始`、`実績終了`、`進捗率`を入力すると、実績バーと遅れ日数が表示されます。
- `種別`を`マイルストーン`にすると、期間1日の重要イベントとしてオレンジ色で表示されます。
- `先行ID`は先行タスクのIDを入力します。マクロ実行時に開始日を自動調整します。
- `休日`シートのA列に休日を追加すると、予定終了日の計算から除外されます。
