# 開発マイルストーン WBS

Excelで使うオリジナルWBSテンプレートです。予定・実績のガントチャート、休日を除いた終了日計算、マイルストーン、カミナリ戦、簡易集計を含みます。

## 作成

```powershell
py -3 .\generate_wbs.py
```

生成物は `開発マイルストーン_WBS.xlsx` です。

## マクロを有効にする場合

1. `開発マイルストーン_WBS.xlsx` をExcelで開きます。
2. `Alt+F11`でVBEを開き、`ファイル > ファイルのインポート`から `WBS_Macro.bas` を読み込みます。
3. 名前を付けて保存で `Excel マクロ有効ブック (*.xlsm)` を選択します。
4. `RefreshWBS` を実行すると、先行タスク、休日、予定終了日、カミナリ戦が更新されます。

## 入力ダイアログ

- WBSシートの入力したい行を選択し、マクロ `InputWBSRow` を実行します。
- タスク名、担当、種別、予定開始日、予定日数、進捗率、先行ID、備考を順番に入力できます。
- WBS表の範囲外を選択して実行した場合は、最初の空き行へ入力します。

## ガント表示期間

- `設定`シートの`B4`にプロジェクト開始月、`B5`にプロジェクト終了月を入力します。
- マクロ `RefreshWBS` または `SetProjectPeriod` を実行すると、開始月の1日から終了月の末日までガントの日付が更新されます。
- マクロ `SetProjectPeriod` を実行すると、開始月と終了月をダイアログで入力できます。
- 日付範囲を変更した後に `RefreshWBS` を実行すると、カミナリ戦も更新されます。

## 入力ルール

- 黄色セルが入力欄です。
- `予定開始` と `予定日数`を入力すると、休日を除いた`予定終了`が計算されます。
- `実績開始`、`実績終了`、`進捗率`を入力すると、実績バーと遅れ日数が表示されます。
- `種別`を`マイルストーン`にすると、期間1日の重要イベントとしてオレンジ色で表示されます。
- `先行ID`は先行タスクのIDを入力します。マクロ実行時に開始日を自動調整します。
- `休日`シートのA列に休日を追加すると、予定終了日の計算から除外されます。
