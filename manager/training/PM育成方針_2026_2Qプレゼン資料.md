### Slide 2: 1Q(7月〜9月)の振り返りと見えてきた課題

#### 1Qの取り組み
- プロジェクト実務を通じた**OJT**と、基礎知識の**座学**を開始
- 実際の案件現場での経験蓄積を最優先に進行

#### 現場から見えてきた3つの課題

| 課題項目 | 1Qの実態 | 発生していた問題 |
|:---|:---|:---|
| **① 到達基準の曖昧さ** | 共通の指標を持たずにプロジェクト個別に実施 | 「どこまでできれば一人前・自走なのか」のゴールが不明確 |
| **② 現在地の可視化不足** | 指導者・本人の感覚による進捗確認 | 個人の強み・弱み、習得済み/未習得スキルの把握が属人化 |
| **③ 教育と評価の分断** | 座学で学んだ内容が現場実務にどう活きたか追跡困難 | OJT機会の有無による不公平感、座学受けっぱなしの発生 |

> **総括**：実案件での経験は得られたものの、**「計画的・体系的な個人の能力向上」**には共通の客観的指標が不可欠であると判明。

---

#### 【発表者ノート】
1Qでは、まず現場で経験を積むことを重視し、OJTと座学を進めてきました。現場での奮闘により確かな第一歩を踏み出せた一方で、明確な統一指標を持っていなかったため、「自分は今どのレベルにいるのか」「指導者として何を基準に評価・育成すべきか」という基準が属人化していました。
また、案件のフェーズや特性によって「この案件ではリスク管理の機会がなかった」「要件定義の場がなかった」といった偏りが生じ、それをどう補うかも曖昧でした。この課題を解決するために作成したのが「PM_指標.xlsx」です。

### Slide 3: 2Q(10月〜)の基本方針・育成コンセプト

#### 基本方針
> **「PM_指標.xlsx」を育成対象者と指導者の共通言語とし、  
> 『現在地の把握 → 計画的習得 → 証跡に基づく自走判定』のサイクルを確立する。**

#### 3つのコアコンセプト

1. **共通の物差し（指標）を持つ**
   - どのプロジェクトに所属していても、公平・一貫した基準で能力を評価・育成
2. **個人の成長にフォーカス（個別最適化）**
   - 一律の詰め込みではなく、個人の強み・伸ばすべき能力に合わせた計画を作成
3. **「自走」を最終ゴールに設定**
   - 指導員の指示待ちを脱し、自ら計画・推進・上申し完結できる状態を目指す

---

#### 【発表者ノート】
2Qからの基本方針は、感覚的な指導から「客観的な指標に基づく計画的育成」への転換です。
「PM_指標.xlsx」は、評価をつけるためだけのシートではありません。育成対象者の皆さんにとっては「自分自身のスキルマップ・成長の羅針盤」であり、指導者にとっては「次に取り組ませるべき業務や課題を見極めるツール」です。
最終的なゴールは、現場で一人で業務をやり切れる「自走」です。

### Slide 4: PM能力フレームワーク（12カテゴリ・49能力）

PMBOK等の国際標準体系に準拠し、PM業務全般を**12カテゴリ・49の必要能力**に体系化。

```
【PM業務のライフサイクルと管理領域】
┌────────────────────────────────────────────────────────┐
│  立ち上げ・計画                                        │
│  ├─ 要件管理 (5能力)         ├─ スコープ管理 (4能力)   │
│  ├─ スケジュール管理 (4能力)  ├─ コスト管理 (4能力)     │
│  └─ 調達・契約管理 (4能力)                              │
├────────────────────────────────────────────────────────┤
│  実行・統制                                            │
│  ├─ 品質管理 (4能力)         ├─ リソース管理 (4能力)   │
│  ├─ コミュニケーション管理 (4能力)                      │
│  ├─ ステークホルダー管理 (4能力)                        │
│  ├─ リスク管理 (4能力)       ├─ 課題・変更管理 (4能力) │
├────────────────────────────────────────────────────────┤
│  終結・活用                                            │
│  └─ 終結・振り返り (4能力)                              │
└────────────────────────────────────────────────────────┘
計 12カテゴリ / 49能力
```

---

#### 【発表者ノート】
「PM_指標.xlsx」では、プロジェクトマネジメントを12のカテゴリに分類し、それぞれに求められる能力を計49個定義しました。
要件定義からスコープ、スケジュール、コスト、品質はもちろん、リソース管理やステークホルダー調整、調達、そして最後の振り返りまでを網羅しています。
シートには各カテゴリごとの個別シートが用意されており、全体像と詳細が直結しています。

### Slide 5: 能力の定義（概要と詳細の分離）

各能力に対し、**「PMに求められる能力の概要」**と**「詳細（具体的行動・証跡）」**を明記。

#### 例：要件管理カテゴリの場合

| 必要な能力 | PMに求められる能力の概要 | 詳細（具体的行動・確認証跡） |
|:---|:---|:---|
| **ヒアリング力** | 関係者の言葉から業務課題、期待成果、制約、優先度を引き出す力。 | 要件管理では要求から受入条件までを一貫して扱い、質問を準備し、事実・要望・推測を区別して聴く。背景や例外を深掘りし、要約確認で認識を合わせ、未確認事項に担当と期限を付ける。評価時は追跡可能な要件・決定記録と未確認事項の一覧を確認し、判断根拠・担当・期限・成果への影響まで説明できること。 |
| **ファシリテーション力** | 関係者が論点に集中し、必要な決定・合意に至る場を設計・進行する力。 | 会議目的・議題・決定者・時間配分を準備する。発言機会を整え、対立を論点と選択肢に整理し、決定・保留理由・担当・期限を記録する。 |

- **メリット**：
  - 抽象的な「ヒアリングができる」ではなく、「何を準備し、何を記録・成果物として残せばよいか」が一目瞭然。

---

#### 【発表者ノート】
能力の定義でこだわった点が、「概要」と「詳細」を分けたことです。
単に「コミュニケーション力」「分析力」と書いてあっても、人によって解釈が異なります。
そのため、概要で「この能力の本質は何か」を一文で示し、詳細で「PM業務において具体的にどう行動し、どんな成果物・証跡を残す必要があるか」を明記しました。これにより、本人も指導者も迷わず同じ基準でスキルを見つめ直すことができます。

### Slide 6: 教育と評価の3本柱（座学・OJT・実践）

「プロジェクト現場で必ずしもOJTの機会があるとは限らない」という現実を踏まえ、**3つのレイヤー**に分離して設計。

```
     ┌─────────────────────────────────────────────────────────┐
     │                      【 実践評価 】                     │
     │   実案件を担当し、定量目標と定性行動の双方で自走度を判定  │
     └────────────────────────────▲────────────────────────────┘
                                  │ 成果・自走へ昇華
     ┌────────────────────────────┴────────────────────────────┐
     │  実務機会がある場合               実務機会がない場合    │
     │  ┌──────────────────────┐         ┌───────────────────┐ │
     │  │     【 OJT教育 】    │         │   【 座学教育 】  │ │
     │  │ 実案件でのOJT・同行  │         │ 講義・良例・ケース│ │
     │  │ 指導者の観察評価     │         │ 理解度テスト・演習│ │
     │  │ (1〜5 / 機会なし)    │         │ (0〜100点、80点目安│ │
     │  └──────────────────────┘         └───────────────────┘ │
     └─────────────────────────────────────────────────────────┘
```

- **座学**：知識のインプットとケース演習（実務がなくても先行して習得可能）
- **OJT**：実際の現場での同行・部分担当・指導者からの直接フィードバック
- **実践**：担当者として自ら推進し、成果物と定量・定性指標で測定

---

#### 【発表者ノート】
ここが本フレームワークの最も重要なポイントです。
1Qでは「OJT機会がないと学べない」「座学をやっても現場で活かせているかわからない」という問題がありました。
そこで今回、教育と評価を「座学」「OJT」「実践」の3本柱に明確に分けました。
案件の都合でOJTができない場合でも、座学やケース演習で先行してインプットを進められます。そして実務機会が訪れた際にOJT・実践へとスムーズに接続する構造にしています。

### Slide 7: 最終指標の定義（「自走できる状態」とは）

座学のテスト合格やOJTの経験だけで終わらせず、**「現場で自走できること」**を最終指標とする。

#### 自走判定の明確な基準

```
┌──────────────────────────────────────────────────────────────────┐
│                   【 自走判定の達成要件 】                       │
│                                                                  │
│  ① 実践定量目標を達成していること                               │
│     （例：計画更新期限遵守率100%、課題追跡率100% 等）            │
│                              ＋                                  │
│  ② 実践定性評価で「レベル4以上」を獲得していること              │
│     （標準業務を自立遂行し、例外時は適時相談・上申ができる）     │
│                              ＋                                  │
│  ③ 上記 ①・② を「連続2回の実務機会」で再現性をもって実証      │
│                              ＋                                  │
│  ④ 成果物・客観的証跡が揃っており、評価者が確認完了している     │
└──────────────────────────────────────────────────────────────────┘
```

> **重要**：一人で抱え込むことが自走ではありません。  
> **「自らの権限内でやり切り、例外やリスクを適切なタイミングで相談・上申できること」**を自走の必須要件としています。

---

#### 【発表者ノート】
本制度の最終ゴールである「自走」の定義です。
「1回たまたまうまくいった」ではなく、「連続2回の実務機会」で定性レベル4以上、かつ定量目標をクリアしていることを条件としました。
ここで特に強調したいのは、「一人で全部抱え込んで誰にも相談しない」のは自走ではないということです。
PMとして自分の権限範囲を理解し、判断できない例外やリスクが生じた際に「選択肢と推奨案を持って適時に上申できる」ことこそが、真の自走です。

---

### Slide 8: 評価方法と運用ルール

客観性と納得感を担保するため、測定方法とルーブリックを統一。

#### 定性評価の共通ルーブリック（1〜5段階）

| レベル | 定義 | 状態の目安 |
|:---:|:---|:---|
| **1** | 未達 | 指導者の手厚い支援や指示があっても遂行が困難 |
| **2** | 指示待ち・要支援 | 手順書や指導者からの頻繁な助言・確認があれば遂行可能 |
| **3** | 一部自立 | 単独で遂行できるが、成果物に手戻りや修正指摘が発生する |
| **4 (自走)** | **自立遂行** | **標準業務を単独で遂行し、例外発生時に適時相談・上申ができる** |
| **5** | 改善・他者支援 | 状況に応じたプロセス改善や、他メンバーの指導・支援ができる |

#### 評価の重要ルール
- **OJTの「機会なし」**：実務機会がなかった場合は「機会なし」を記録（減点・未達扱いにしない）。
- **座学評価**：出席確認ではなく、理解度テスト・ケース課題で**80点以上**を基準とする。
- **証跡主義**：評価には必ず成果物（計画書、WBS、議事録、課題票等）の証跡を添える。

---

#### 【発表者ノート】
評価基準の曖昧さを排除するため、定性評価には1〜5の共通ルーブリックを採用しました。Excel上でも入力規則により1〜5（OJTは「機会なし」を含む）のみが選択できるよう制限しています。
また、実務機会に恵まれなかった項目について「未達（レベル1）」とするのではなく、「機会なし」として記録し、次期以降の育成計画で優先的にアサインする材料として扱います。

### Slide 9: 2Q以降の育成運用サイクル（PDCA）

四半期ごとに以下のサイクルを回し、着実なステップアップを図る。

```
【期初 (月初)】
  1. 現状アセスメント（自己評価・指導者評価で現在地を確認）
  2. 今期の「重点育成能力」（2〜3カテゴリ、3〜5能力程度）を選定
  3. 定量目標値・対象案件・証跡の合意
         │
         ▼
【期中 (月次)】
  1. 座学・ケース演習の受講（インプット）
  2. プロジェクト実務でのOJT・実践アサイン
  3. 月次1on1での進捗確認・フィードバック（気づきの言語化）
         │
         ▼
【期末 (四半期末)】
  1. 実績証跡の持ち寄り・定量/定性評価の確定
  2. 自走度判定（連続2回達成の確認）
  3. 次期（3Q）の重点テーマ選定への引き継ぎ
```

---

#### 【発表者ノート】
運用の流れです。
49の能力すべてを3ヶ月で一気にマスターすることは不可能です。
期初に現状の棚卸しを行い、「今期はこの3つの能力を重点的に伸ばす」と絞り込んでコミットします。
月次の1on1で状況を確認しながら進め、四半期末に評価と自走判定を行います。これを繰り返すことで、無理なく確実に能力の幅を広げていきます。

### Slide 10: 育成対象者・指導員への期待

#### 育成対象者（皆さん）へ期待すること
- **受け身の脱却**：「何をすればよいか」を待つのではなく、指標を見て自ら「この業務に挑戦させてほしい」と手を挙げる。
- **証跡を意識した仕事**：日頃から議事録、WBS、課題管理表などの成果物の品質と根拠にこだわる。
- **早い相談・早い上申**：壁にぶつかったら抱え込まず、選択肢を持って指導者に相談する。

#### 指導員（メンター・PM）へ期待すること
- **感覚的な指導からの脱却**：指標の言葉を使って「何ができていて、何が不足しているか」を具体的にフィードバックする。
- **機会の意図的な創出**：育成対象者の重点能力に合わせ、会議のファシリテーションや計画作成などの実務機会を任せる。
- **心理的安全性の確保**：失敗を恐れず挑戦できるよう、早いアラートを歓迎する雰囲気を作る。

---

#### 【発表者ノート】
この仕組みを機能させる最大の鍵は、育成対象者と指導員のパートナーシップです。
対象者の皆さんは、この指標を「会社からのノルマ」ではなく「自分の市場価値を高めるチェックリスト」と捉えて主体的に活用してください。
指導員の皆さんは、単なる粗探しではなく、「どうすればこの項目でレベル4に到達できるか」を一緒に考える伴走者としてサポートをお願いします。

### Slide 12: まとめ

## 付録：PM_指標.xlsx シート構成リファレンス

- **「指標」シート**：全12カテゴリと主な業務・必要能力の鳥瞰図（各シートへのハイパーリンク付き）
- **「マップ」シート**：能力間の横断マップ
- **各カテゴリシート（12シート）**：
  - 列A：必要な能力
  - 列B：PMに求められる能力の概要
  - 列C：詳細（具体的行動・確認証跡）
  - 列D：OJT教育方法
  - 列E：OJT評価基準
  - 列F：OJT評価（1〜5 / 機会なし）
  - 列G：座学教育方法
  - 列H：座学評価基準
  - 列I：座学評価（点/100）
  - 列J：実践評価（定量指標）
  - 列K：実践評価（定性指標）
  - 列L：実践定量実績・証跡
  - 列M：実践定性評価（1〜5）
  - 列N：自走判定・次の育成
