# PM／PMO 座学カリキュラム

## 1. この資料の目的

本資料は、開発未経験者が3年間でPMまたはPMOとして実務を担えるようになるために、座学で身につける知識と学習方法を整理したものである。

座学は単独で完結させず、各テーマをOJTで実際に使い、成果物と振り返りで理解度を確認する。学習時間の目安は、通常業務に加えて週2～3時間とする。繁忙期は無理に時間を確保せず、テーマを分割して継続する。

### 座学の基本サイクル

1. 事前学習：用語、考え方、基本手順を学ぶ
2. 集合学習：講義、ケース討議、ロールプレイで理解を深める
3. OJT適用：実際の会議、計画、報告、管理表で使う
4. 成果物レビュー：上司またはメンターから具体的なフィードバックを受ける
5. 説明・振り返り：本人が学んだ内容と判断理由を説明する

### 理解度の判定

| レベル        | 判定基準                                     |
| ------------- | -------------------------------------------- |
| レベル1：知識 | 用語や基本的な考え方を説明できる             |
| レベル2：適用 | 指導を受けながら、実際の成果物や会議で使える |
| レベル3：自走 | 状況に応じて使い分け、理由を説明できる       |
| レベル4：展開 | 他者に教え、標準化や改善に活用できる         |

## 5. 学習方法の使い分け

### 5-1. 自習

- 社内標準、過去案件の計画書、議事録、報告書を読む
- PMBOKなどの体系書、開発手法の入門書、動画講座を利用する
- 1回30～45分で区切り、学習後に「実務で何に使うか」を1行で記録する
- 分からない用語を用語集に登録し、翌週の1on1で確認する

自習は知識の入口として利用し、読了数や受講時間だけで理解度を評価しない。

### 5-2. 講義・社内勉強会

- 月1回、60～90分のテーマ講義を行う
- 講義の最後に、自社の実案件へ適用する課題を1つ出す
- PM、PMO、技術リーダー、営業、品質担当など、テーマに応じて講師を変える
- 受講者には、次回までに成果物または実践結果を提出してもらう

### 5-3. ケーススタディ

実際の失敗を個人攻撃にならないよう匿名化し、次の順番で検討する。

1. 何が起きたかを事実で整理する
2. どの時点で兆候を捉えられたかを考える
3. 選択肢とそれぞれの影響を比較する
4. 誰に、いつ、何を報告・相談するかを決める
5. 再発防止を仕組みに落とし込む

### 5-4. ロールプレイ

PMでは顧客交渉、遅延報告、変更承認、障害対応を扱う。PMOでは状況報告、データ不備の是正依頼、会議の合意形成、標準化の導入を扱う。

実施後は、話し方の印象だけでなく、目的、事実、論点、選択肢、依頼事項、記録の有無を評価する。

### 5-5. 教える学習

- 3か月に1回、本人が15～30分のミニ勉強会を担当する
- 対象者に合わせて、用語、事例、演習、確認問題を準備する
- 質問に答えられなかった点を、次の学習テーマとして記録する

他者に教えることは、知識の定着と説明力の確認に使う。ただし、講師経験の有無だけで人を評価しない。

## 6. 年次の学習計画

### 1年目

- 週2時間：共通基礎の自習と用語整理
- 月1回：IT・開発工程・プロジェクト管理の講義
- 四半期ごと：ケーススタディまたはロールプレイ
- 年末：PM体験とPMO体験の成果発表

### 2年目

- 週2～3時間：選択ルートの専門学習
- 月1回：実案件の成果物レビューと専門テーマ講義
- 四半期ごと：PMまたはPMOのケース演習
- 年末：副担当としての実践成果と改善提案を発表

### 3年目

- 週1～2時間：高度テーマの自習と実案件への適用
- 月1回：上位PM、PMO責任者、経営・品質担当との勉強会
- 四半期ごと：重大事象または経営報告のシミュレーション
- 年末：3年間の成長、成果、今後の専門領域を発表

## 7. 教材と講師の選び方

### 教材

- 自社の開発標準、規程、過去案件の成果物を最優先する
- 一般書籍や動画は、用語や考え方を補う目的で使う
- 資格試験の教材は体系的な学習に活用するが、合格だけを到達目標にしない
- 顧客情報、個人情報、契約情報を含む資料は匿名化して利用する

### 講師

- PM：上位PM、経験のあるプロジェクトリーダー、顧客対応経験者
- PMO：PMO責任者、品質・経営管理・業務改善の担当者
- 共通：技術リーダー、セキュリティ担当、人事・コンプライアンス担当

講師には、知識の説明だけでなく、自社の判断基準、失敗例、相談先、実務での注意点を含めてもらう。

## 8. 座学の記録と評価

各テーマについて、次の項目を学習記録に残す。

- 学習日、テーマ、学習時間
- 学んだ用語・考え方
- OJTで使った場面
- 作成した成果物
- 指導者からのフィードバック
- まだ一人では判断できないこと
- 次に実践すること

評価面談では、受講時間やテストの点数だけでなく、実務成果物、判断理由、相談のタイミング、学習内容を他の場面へ応用したかを確認する。

## 9. 推奨する資格・外部学習

資格取得は本人の希望と業務上の必要性を確認して選択する。資格を取らないことを、PMまたはPMOとしての不適格とみなさない。

候補となる学習テーマは以下のとおりである。

- プロジェクトマネジメントの基礎資格・体系学習
- アジャイル、スクラムの基礎
- ITパスポート相当のIT基礎
- 情報セキュリティ、個人情報保護
- 表計算、データ可視化、統計の基礎
- ファシリテーション、コーチング、交渉

外部講座や資格で学んだ内容は、社内案件の成果物に適用し、本人の言葉で振り返るところまでを学習完了とする。
