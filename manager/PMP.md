| テーラリング               | プロジェクトの規模、複雑さ、環境、ステークホルダーのニーズに合わせて、PMBOKなどの標準的なプロセス、ツール、手法、アプローチを意図的に調整・最適化する作業のこと。        | [テーラリング](https://repsona.com/ja/pm-handbook/006000-what-is-tailoring)                                                |
| 従来型(ウォーターフォール) | ウォーターフォール（予測型アプローチ）とは、要件や計画を最初にはっきり固め、上流工程から下流工程へと順番に作業を進める直線的なプロジェクト管理手法のこと                 | [ウォーターフォール](https://www.e-project.jp/blog/hibrid-pmp/)                                                            |
| アジャイル型               | 変化の激しい要件や不確実性の高い環境に対応するため、短期間のサイクル（イテレーションやスプリント）を繰り返しながら少しずつ価値を届けるプロジェクトマネジメント手法のこと | [アジャイル型](https://iret.media/184420)                                                                                  |
| ハイブリット型             | 「予測型（ウォーターフォール）」と「アジャイル型（適応型）」の2つの手法を組み合わせたプロジェクト管理の進め方                                                            | [ハイブリット型](https://www.e-project.jp/blog/hibrid-pmp/)                                                                |
| ビジネスアナリシス         | 組織が目指す価値を実現するために、課題や機会を分析し、関係者のニーズを明確化して、最適な変革を導く活動                                                                   |                                                                                                                            |
| 戦略(Strategy)             | 組織が目指す方向性や方針（経営戦略、企業戦略、中期経営計画など）                                                                                                         |                                                                                                                            |
| 目標（Objectives）         | 戦略を実現するために設定する具体的な目標                                                                                                                                 |                                                                                                                            |
| 施策（Initiatives）        | 目標達成のために実施するポートフォリオ、プログラム、プロジェクト                                                                                                         |                                                                                                                            |
| 成果物（Deliverables）     | プログラムやプロジェクトによって生み出されるアウトプット                                                                                                                 |                                                                                                                            |
| 能力（Capability）         | 成果物の活用によって組織にもたらされる業務遂行能力や実現能力                                                                                                             |                                                                                                                            |
| 成果（Outcome）            | 能力の発揮によって得られる事業上の結果や変化                                                                                                                             |                                                                                                                            |
| ベネフィット（Benefit）    | 成果によって得られる利益や効果                                                                                                                                           |                                                                                                                            |
| 価値（Value）              | ベネフィットからコストを差し引いたもの（Value = Benefit − Cost）                                                                                                         |                                                                                                                            |

## プロジェクトの計画

### プロジェクト方法論と実務の決定

- 価値実現のライフサイクル
  - ビジネスアナリシス： 組織が目指す価値を実現するために、課題や機会を分析し、関係者のニーズを明確化して、最適な変革を導く活動
    - 戦略(Strategy)： 組織戦略(経営戦略、企業戦略、中計)
    - 目標(Objectives)：戦略目標
    - 施策：ポートフォリオ、プログラム、プロジェクト
    - 成果物(Deliverables)：プログラムやプロジェクトのアウトプット
    - 能力(Capability)：達成能力
    - 成果(Outcome)：成果物の結果
    - ベネフィット(Benefit)：受益
    - 価値(Value): 価値 = Benefit - Cost
