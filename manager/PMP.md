# PMP

## 用語集

| 用語                       | 概要                                                                                                                                                                     | 参照先                                                                                                                     |
| :------------------------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------- |
| ブルックスの経験則         | ソフトウェア開発などのプロジェクトにおいて、「遅れているプロジェクトにさらに人員を追加しても、かえってさらに遅れる」という直感に反する経験則です 。                      | [ブルックスの法則](https://ja.wikipedia.org/wiki/%E3%83%96%E3%83%AB%E3%83%83%E3%82%AF%E3%82%B9%E3%81%AE%E6%B3%95%E5%89%87) |
| アジャイルマニュフェスト   | 2001年にアメリカで発表された、柔軟で素早いソフトウェア開発の基本的な考え方を示す指針です。                                                                               | [アジャイルマニュフェスト](https://agilemanifesto.org/iso/ja/manifesto.html)                                               |
| フィーチャー               | ユーザーに価値を提供するまとまりとしての「ソフトウェアの機能」や「機能群」のことです。                                                                                   | [フィーチャー](https://note.com/shinhikamiya_513/n/n483674c81072)                                                          |
| スクラム                   | スクラムは、少人数のチームが短期間のサイクル（スプリント）を繰り返して価値を最大化するアジャイル手法です。                                                               | [スクラム](https://www.youtube.com/watch?app=desktop&v=wNEisnHDxdI&t=60)                                                   |
| テーラリング               | プロジェクトの規模、複雑さ、環境、ステークホルダーのニーズに合わせて、PMBOKなどの標準的なプロセス、ツール、手法、アプローチを意図的に調整・最適化する作業のこと。        | [テーラリング](https://repsona.com/ja/pm-handbook/006000-what-is-tailoring)                                                |
| 従来型(ウォーターフォール) | ウォーターフォール（予測型アプローチ）とは、要件や計画を最初にはっきり固め、上流工程から下流工程へと順番に作業を進める直線的なプロジェクト管理手法のこと                 | [ウォーターフォール](https://www.e-project.jp/blog/hibrid-pmp/)                                                            |
| アジャイル型               | 変化の激しい要件や不確実性の高い環境に対応するため、短期間のサイクル（イテレーションやスプリント）を繰り返しながら少しずつ価値を届けるプロジェクトマネジメント手法のこと | [アジャイル型](https://iret.media/184420)                                                                                  |
| ハイブリット型             | 「予測型（ウォーターフォール）」と「アジャイル型（適応型）」の2つの手法を組み合わせたプロジェクト管理の進め方                                                            | [ハイブリット型](https://www.e-project.jp/blog/hibrid-pmp/)                                                                |
